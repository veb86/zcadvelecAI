Тест парсера шаблонов для issue #713
========================================

Примеры из технического задания:

1. Шаблон с комбинацией всех типов:
   Входной шаблон: @@[SLCABAGEN<lnum>_SLTypeagen]_@@[NMO_BaseName]!!!<Name>

   Где:
   - SLCABAGEN1_SLTypeagen = "ЭО"
   - NMO_BaseName = "EL1"
   - Name (системный атрибут) = "VEL_LIGHT_2x36"
   - lnum = 1

   Ожидаемый результат: ЭО_EL1!!!VEL_LIGHT_2x36

2. Шаблон только с системными атрибутами:
   Входной шаблон: <Type>_<ID>

   Ожидаемый результат: зависит от типа и ID объекта

3. Шаблон со статическими разделителями:
   Входной шаблон: Device: <Name> (Type: <Type>, ID: <ID>)

   Ожидаемый результат: Device: VEL_LIGHT_2x36 (Type: 123, ID: 456)

Реализация:
-----------
- Создан модуль uzvsqlite_template_parser.pas
- Функция ParseTemplate() обрабатывает шаблоны
- Функция GetSystemAttribute() получает системные атрибуты
- Функция GetDynamicParameter() получает динамические параметры через FindVariableInEnt
- Интеграция в uzvsqlite_executor.pas в функции ExtractValues()

Поддерживаемые системные атрибуты:
----------------------------------
- <Name> - имя объекта
- <ID> - ID объекта
- <Type> - тип объекта
- <Layer> - имя слоя

Поддерживаемые плейсхолдеры:
----------------------------
- @@[param_name] - динамический параметр
- <AttributeName> - системный атрибут
- <lnum> внутри @@[] - номер цикла
- Обычный текст - копируется как есть
