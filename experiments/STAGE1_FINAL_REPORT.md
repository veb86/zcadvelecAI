## 📋 Ключевые выводы

### Polyface Mesh vs 3D Polyline:
| Параметр | 3D Polyline | Polyface Mesh |
|----------|--------------|---------------|
| **Флаг 70** | 8 | **64** |
| **Данные** | Последовательность вершин | **Вершины + грани** |
| **Назначение** | Линии | **Поверхность** |
| **VERTEX типы** | Координатные | **Координатные + индексные** |

### Формат DXF Polyface Mesh:
```
POLYLINE
  70    ; 64 = polyface mesh (+1 = closed)
  71    ; количество вершин (опционально)
  72    ; количество граней (опционально)
VERTEX     ; координатные вершины (N штук)
  10,20,30 ; X,Y,Z координаты
...
VERTEX     ; вершины граней (M штук)  
  70    ; 128 = флаг вершины грани
  10,20,30 ; индексы вершин (1,2,3,4)
...
SEQEND
```

### Подтверждение из существующего кода ZCAD:
```c
// Из DWG реализации - подтверждает правильность анализа
typedef struct _dwg_entity_POLYLINE_PFACE {
  BITCODE_BS flag;     // флаги (64 для polyface)
  BITCODE_BS numverts; // количество вершин  
  BITCODE_BS numfaces; // количество граней
} Dwg_Entity_POLYLINE_PFACE;

typedef struct _dwg_entity_VERTEX_PFACE_FACE {
  BITCODE_RC flag;     // 128 для face-вершины
  BITCODE_BS vertind[4]; // до 4 индексов вершин
} Dwg_Entity_VERTEX_PFACE_FACE;
```

## 🏗️ Предлагаемая архитектура реализации

### Основные классы:
1. **GDBObjPolyFaceMesh** - наследник `GDBObjCurve`
2. **GDBFaceRecord** - запись грани с 4 индексами
3. **GDBFaceArray** - контейнер для граней

### Интеграция в систему:
- **ID**: `GDBPolyFaceMeshID = 17`
- **DXF Name**: `'POLYLINE'` (как и обычный polyline)
- **User Name**: `'PolyFaceMesh'`
- **Detection**: флаг 64 в группе 70 отличает от обычного polyline

### Обязательные методы (чеклист):
- [ ] `LoadFromDXF()` - парсинг с определением типа VERTEX
- [ ] `SaveToDXF()` - сохранение с флагом 64
- [ ] `DrawGeometry()` - отрисовка полигонов
- [ ] `GetObjType()` / `GetObjTypeName()`
- [ ] Фабричные методы: `CreateInstance()`, `Alloc...()`
