## Ключевое открытие

**Версия формата (байты 4-7) определяет тип объекта**:

| Версия | Тип объекта | Geometry |
|--------|-------------|----------|
| 24 (0x18) | SPDSPOLYMORPHMARK | Круг |
| 41 (0x29) | SPDSNOTEPOSITION | Выноска (стрелка + текст) |

**Идентификатор типа примитива (Окружность/Линия/Дуга) НЕ хранится в бинарных данных!**

Он определяется из:
1. **Версии формата** (24 = SPDSPOLYMORPHMARK)
2. **Текстовых параметров** (Shape: Окружность)

## Поиск координат текста

### Проблема

В бинарных данных SPDSPOLYMORPHMARK найдены:
- Координаты центра круга (байты 252-283)
- 9 вершин Display Mesh (байты 200-295)

**НЕ найдены**: Отдельные координаты для текста.

### Гипотеза: Текст центрируется автоматически

Поскольку:
1. В текстовых параметрах нет отдельных координат для текста
2. Shape: Окружность подразумевает симметрию
3. Text height: 3.5 (относительно Size: 7.0)

**Текст позиционируется в центре круга**:
```
TextX = CenterX = 3865.2805
TextY = CenterY = 1948.4385
TextZ = CenterZ = 0.0
```

### Проверка гипотезы

Нужно найти в бинарных данных другие структуры double которые могли бы быть координатами текста.

**Поиск в байтах 400-600**:

| Байт | Hex | Значение | Интерпретация |
|------|-----|----------|---------------|
| 432-439 | 74 92 C3 D7 0F 4B A9 40 | 3866.7150 | Точка на окружности (mesh) |
| 440-447 | 4C 73 09 F9 A8 48 A0 40 | 2131.8730 | Точка на окружности (mesh) |
| 504-511 | 00 E0 75 40 ... | 300.0 | Параметр (не координата) |
| 512-519 | 00 00 F0 3F ... | 1.0 | Масштаб |

**Вывод**: Все найденные double — это либо вершины mesh, либо параметры. Отдельных координат текста нет.

## Взаимосвязь данных

### Текстовые параметры → Бинарные данные

| Текстовый параметр | Где в бинарных данных |
|-------------------|----------------------|
| Shape: Окружность | Версия формата = 24 |
| Size: 7.0 | НЕ найдено напрямую (возможно в промежуточных данных) |
| Text: 9 | НЕ хранится в бинарных данных! |
| Text height: 3.5 | НЕ найдено напрямую |
| Text style: ГОСТ 2.304 | Имя файла "CS_Gost2304.shx" (байты 548-578) |

### Координаты текста

**Вывод**: Координаты текста **НЕ хранятся отдельно**. Текст позиционируется автоматически:

```
Для SPDSPOLYMORPHMARK (Shape: Окружность):
  TextPosition = CircleCenter
```

## Алгоритм чтения прокси-объекта

```pascal
procedure ReadProxyObject(const hexData: string);
var
  buffer: TBytes;
  formatVersion: Integer;
  centerX, centerY, centerZ, radius: Double;
  textContent: string;
  textPosition: TPoint3D;
begin
  buffer := HexToBytes(hexData);
  
  // Читаем версию формата
  formatVersion := ReadInteger(buffer, 4);
  
  case formatVersion of
    24: // SPDSPOLYMORPHMARK (круг)
      begin
        // Читаем геометрию круга
        centerX := ReadDouble(buffer, 252);
        centerY := ReadDouble(buffer, 260);
        centerZ := ReadDouble(buffer, 268);
        radius := ReadDouble(buffer, 276);
        
        // Текст центрируется в центре круга
        textPosition := Point3D(centerX, centerY, centerZ);
        
        // Текст берётся из текстовых параметров (код 300/301)
        textContent := GetTextParam('Text');
      end;
      
    41: // SPDSNOTEPOSITION (выноска)
      begin
        // Читаем геометрию выноски (другая структура)
        // ...
      end;
  end;
end;
```

## Что делать дальше

### 1. Проверить другие файлы

Найти DXF файлы с другими типами SPDSPOLYMORPHMARK:
- Shape: Квадрат
- Shape: Линия
- Shape: Дуга
- Shape: Прямоугольник

Сравнить их бинарные данные:
- Изменилась ли версия формата?
- Изменилась ли структура геометрии?

### 2. Поиск Size в бинарных данных

Size: 7.0 может храниться в одном из полей:
- Байты 120-135: параметр 98.0 (не подходит)
- Байты 420-430: параметр 200 (не подходит)
- Текстовые параметры (код 40)

**Возможно**: Size используется только для отображения в UI, а реальная геометрия определяется Radius из бинарных данных.

### 3. Экспериментальная проверка

Создать тестовый DXF с теми же параметрами но разными координатами:
- Изменить Center X,Y
- Изменить Radius
- Проверить что изменилось в бинарных данных

## Формула для отрисовки

```pascal
// Для SPDSPOLYMORPHMARK с Shape: Окружность
procedure DrawSPDSPolymorphMark;
begin
  // 1. Рисуем круг
  Circle.Create(
    Center: Point3D(centerX, centerY, centerZ),
    Radius: radius
  );
  
  // 2. Рисуем текст в центре
  Text.Create(
    Position: Point3D(centerX, centerY, centerZ),
    Content: textContent,  // из текстовых параметров
    Height: textHeight,    // из текстовых параметров
    Style: textStyle       // из текстовых параметров
  );
end;
```
