# Итоговая структура данных SPDSPOLYMORPHMARK

## Связь между текстовыми параметрами и бинарными данными

### Формат хранения данных

Прокси-объект СПДС хранит данные в **ДВУХ независимых потоках**:

| Поток | Коды DXF | Что хранит | Пример |
|-------|----------|------------|--------|
| **Бинарные данные** | 310 (hex-строка) | Геометрия для отрисовки | Координаты, mesh, BBox |
| **Параметры объекта** | 300, 301, 40, 90, 290 | Состав и свойства | "Окружность", "9", "7.0" |

## Ключевые открытия

### 1. Идентификатор типа примитива

**Где**: Байты 4-7 бинарных данных (код 310)

| Значение | Тип объекта | Форма |
|----------|-------------|-------|
| 24 (0x18) | SPDSPOLYMORPHMARK | Окружность |
| 41 (0x29) | SPDSNOTEPOSITION | Выноска |

**Важно**: Число 24 НЕ означает "Окружность" напрямую. Это идентификатор формата SPDSPOLYMORPHMARK.
А уже в текстовых параметрах указано Shape: Окружность.

### 2. Координаты текста

**Где**: НЕ хранятся в бинарных данных!

Текст позиционируется **автоматически**:
```
TextPosition = CircleCenter
```

Для SPDSPOLYMORPHMARK с формой "Окружность" текст всегда в центре круга.

### 3. Size (7.0)

**Где**: Только в текстовых параметрах (код 40)

В бинарных данных НЕ найдено. Возможно:
- Используется только для UI
- Реальный размер определяется Radius из бинарных данных
- Size = 2 × Radius / Scale = 2 × 366.869 / 100 ≈ 7.34 (близко к 7.0)

## Алгоритм чтения SPDSPOLYMORPHMARK

```pascal
procedure ReadSPDSPolymorphMark(const entityData: TDXFEntity);
var
  formatVersion: Integer;
  centerX, centerY, centerZ, radius: Double;
  textContent, textStyle, shapeType: string;
  textHeight, size, scale: Double;
  textPosition: TPoint3D;
begin
  // 1. Читаем текстовые параметры
  shapeType := entityData.Params['Shape'];      // "Окружность"
  textContent := entityData.Params['Text'];     // "9"
  textStyle := entityData.Params['Text style']; // "ГОСТ 2.304"
  textHeight := entityData.Params['Text height']; // 3.5
  size := entityData.Params['Size'];            // 7.0
  scale := entityData.Params['Scale'];          // 100.0
  
  // 2. Читаем бинарные данные
  formatVersion := ReadInteger(entityData.BinaryData, 4);
  
  // 3. Проверяем тип объекта
  if formatVersion = 24 then
  begin
    // SPDSPOLYMORPHMARK
    
    // 4. Читаем геометрию круга
    centerX := ReadDouble(entityData.BinaryData, 252);
    centerY := ReadDouble(entityData.BinaryData, 260);
    centerZ := ReadDouble(entityData.BinaryData, 268);
    radius := ReadDouble(entityData.BinaryData, 276);
    
    // 5. Вычисляем позицию текста (центр круга)
    textPosition := Point3D(centerX, centerY, centerZ);
    
    // 6. Рисуем круг
    DrawCircle(Point3D(centerX, centerY, centerZ), radius);
    
    // 7. Рисуем текст в центре
    DrawText(textContent, textPosition, textHeight, textStyle);
  end
  else if formatVersion = 41 then
  begin
    // SPDSNOTEPOSITION (выноска)
    // Другая структура данных...
  end;
end;
```

## Алгоритм записи SPDSPOLYMORPHMARK

```pascal
procedure WriteSPDSPolymorphMark(
  const center: TPoint3D;
  radius: Double;
  const textContent: string;
  const textStyle: string;
  textHeight: Double;
  size: Double
): TDXFEntity;
var
  binaryData: TBytes;
  fontName: string;
begin
  // 1. Инициализируем буфер (944 байта)
  SetLength(binaryData, 944);
  
  // 2. Записываем заголовок
  WriteInteger(binaryData, 0, 944);      // Размер данных
  WriteInteger(binaryData, 4, 24);       // Версия формата (24 = SPDSPOLYMORPHMARK)
  WriteInteger(binaryData, 8, 136);      // Смещение
  WriteInteger(binaryData, 12, 29);      // Размер заголовка
  WriteDouble(binaryData, 20, 1.0);      // Масштаб
  
  // 3. Записываем геометрию круга
  WriteDouble(binaryData, 252, center.X);
  WriteDouble(binaryData, 260, center.Y);
  WriteDouble(binaryData, 268, center.Z);
  WriteDouble(binaryData, 276, radius);
  
  // 4. Записываем Display Mesh (9 вершин, 5 граней)
  // ... (генерация меша для круга)
  
  // 5. Записываем имя шрифта (UTF-16 LE)
  fontName := 'CS_Gost2304.shx';
  WriteUTF16LE(binaryData, 548, fontName);
  
  // 6. Записываем завершающие данные
  // ...
  
  // 7. Создаём DXF сущность
  Result := TDXFEntity.Create;
  Result.TypeName := 'SPDSPOLYMORPHMARK';
  Result.BinaryData := BytesToHex(binaryData);
  
  // 8. Добавляем текстовые параметры
  Result.Params['Name'] := textContent;
  Result.Params['Info'] := 'Позиционный маркер';
  Result.Params['Shape'] := 'Окружность';
  Result.Params['Size'] := size;
  Result.Params['Text'] := textContent;
  Result.Params['Text height'] := textHeight;
  Result.Params['Text style'] := textStyle;
  Result.Params['Scale'] := 100.0;
  Result.Params['CutAcElements'] := 'Маскированием';
end;
```

### Контрольные точки для отладки

| Байт | Ожидаемое значение | Описание |
|------|-------------------|----------|
| 0-3 | 944 (0x3B0) | Размер данных |
| 4-7 | 24 (0x18) | Версия формата |
| 252-259 | 3865.2805 | Center X |
| 260-267 | 1948.4385 | Center Y |
| 276-283 | 366.869 | Radius |
| 548-578 | "CS_Gost2304.shx" | Имя шрифта |

### Формулы для проверки

```
BBoxMin = (CenterX - Radius, CenterY - Radius, 0)
BBoxMax = (CenterX + Radius, CenterY + Radius, 0)

Для маркера "9":
BBoxMin = (3865.2805 - 366.869, 1948.4385 - 366.869, 0)
        = (3498.4115, 1581.5695, 0)
BBoxMax = (3865.2805 + 366.869, 1948.4385 + 366.869, 0)
        = (4232.1495, 2315.3075, 0)
```

## Выводы

1. **Тип примитива** определяется из версии формата (байты 4-7), но дублируется в текстовых параметрах (Shape: Окружность).

2. **Координаты текста** НЕ хранятся — вычисляются как центр круга.

3. **Size (7.0)** хранится только в текстовых параметрах, не в бинарных данных.

4. **Текстовое содержимое** ("9", "1") хранится ТОЛЬКО в текстовых параметрах (код 300/301), НЕ в бинарных данных.

5. **Геометрия** (центр, радиус) хранится ТОЛЬКО в бинарных данных (код 310).

6. **Два потока данных независимы**: можно изменить текст ("9" → "1") не меняя бинарные данные.
