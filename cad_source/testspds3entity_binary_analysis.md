# Поиск связи между составом объекта и бинарными данными

## Проблема

В текстовых параметрах (коды 300/301/40) указано:
```
301 Shape
300 Окружность
301 Size
 40 7.0
```

Но в бинарных данных (код 310) **не найден явный идентификатор типа "Circle"**.

## Гипотезы

### Гипотеза 1: Идентификатор типа в заголовке

Возможно тип примитива закодирован в одном из полей заголовка:

| Байт | Hex | Значение | Возможная интерпретация |
|------|-----|----------|------------------------|
| 4-7 | 18 00 00 00 | 24 | Версия формата? Или тип объекта? |
| 16-19 | 00 00 00 00 | 0 | Флаги? (бит 0 = Circle, бит 1 = Line, и т.д.) |

### Гипотеза 2: Структура "запись с типом"

Бинарные данные могут содержать записи вида:
```
[4 байта: тип][4 байта: размер][N байт: данные]
```

Например:
- Тип 1 = Circle
- Тип 2 = Line
- Тип 3 = Text
- Тип 4 = Arc

### Гипотеза 3: Тип определяется порядком

Первая геометрическая запись = основной примитив (Circle)
Вторая геометрическая запись = текст

### Гипотеза 4: Тип хранится в текстовых данных, а не бинарных

**Наиболее вероятно**: Бинарные данные содержат ТОЛЬКО геометрию (координаты), а тип примитива определяется из текстовых параметров (Shape: Окружность).

## Где координаты текста?

### Проблема

В бинарных данных найдены:
- Координаты центра круга (байты 252-283)
- 9 вершин mesh (байты 200-295)

**НЕ найдены**:
- Координаты текста (должны быть отдельные X, Y, Z)

### Гипотезы

#### Гипотеза 1: Координаты текста вычисляются

Текст центрируется относительно центра круга:
```
TextX = CenterX
TextY = CenterY
TextZ = CenterZ
```

#### Гипотеза 2: Координаты текста в другом месте

Поиск структур double в данных:

**Строка 5, байты ~300-350**:
```
06 00 00 00 = 6 (количество?)
05 00 00 00 = 5 (количество треугольников?)
00 00 00 00 = индекс 0
01 00 00 00 = индекс 1
02 00 00 00 = индекс 2
03 00 00 00 = индекс 3
04 00 00 00 = индекс 4
```

Это индексы вершин mesh, не координаты текста.

**Строка 5, байты ~430-450**:
```
74 92 C3 D7 0F 4B A9 40 = 3866.7150 (X?)
4C 73 09 F9 A8 48 A0 40 = 2131.8730 (Y?)
```

Это вершина mesh (точка на окружности), не текст.

#### Гипотеза 3: Координаты текста в текстовых параметрах

Возможно координаты текста хранятся в кодах 10, 20, 30 (как у MText), но в нашем файле их нет.

#### Гипотеза 4: Текст всегда в центре

Для SPDSPOLYMORPHMARK текст всегда позиционируется в центре круга автоматически.
