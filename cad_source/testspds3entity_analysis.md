# Расшифровка DXF файла testspds3entity.dxf

## Общая информация о файле

| Параметр | Значение |
|----------|----------|
| Версия AutoCAD | AC1021 (AutoCAD 2007) |
| Кодовая страница | ANSI_1251 (кириллица) |
| Последний сохранивший | BobrovV |
| PROXYGRAPHICS | 1 (сохранять прокси-объекты) |
| Единицы измерения | Миллиметры (INSUNITS = 4) |

## Структура DXF файла

Файл содержит следующие секции:

```
testspds3entity.dxf
├── HEADER          # Системные переменные
├── CLASSES         # Определения классов прокси-объектов
├── TABLES          # Таблицы символов (VPORT, LTYPE, LAYER, STYLE, и т.д.)
├── BLOCKS          # Определения блоков
├── ENTITIES        # Графические объекты (SPDSPOLYMORPHMARK, SPDSNOTEPOSITION)
├── OBJECTS         # Негранфические объекты (словари, переменные)
└── THUMBNAILIMAGE  # Миниатюра (опционально)
```

## 4. Где хранится proxy-графика

### 4.1 Места хранения

Данные прокси-объекта разделены на **ДВА независимых потока**:

| Поток | Коды DXF | Что хранит |
|-------|----------|------------|
| **Бинарные данные** | 310 (hex-строка) | Геометрия (координаты, mesh, BBox) |
| **Текстовые/числовые данные** | 300, 301, 40, 90, 290 | Параметры объекта (текст, стиль, форма, размер) |

**Важно**: Состав примитивов (например, "Окружность", "Текст", "Размер 7.0") хранится в **текстовых кодах (300, 301, 40)**, а НЕ в бинарных данных (310)!

| Место | Код DXF | Формат | Назначение |
|-------|---------|--------|------------|
| **ENTITIES** | 310 | Hex-строка | Бинарные данные геометрии |
| **ENTITIES** | 300, 301 | Текст | Строковые параметры (имя, тип, стиль) |
| **ENTITIES** | 40, 90 | Double/Int | Числовые параметры (размер, масштаб) |
| **ENTITIES** | 290 | Boolean | Флаги (многострочный режим) |
| **OBJECTS** | 310 | Hex-строка | Словари и настройки |

### 4.2 Формат бинарных данных (код 310)

**Структура данных**:

```
+------------------+
| Заголовок (29B)  |  ← Размер, версия, смещения
+------------------+
| Данные геометрии |  ← Координаты, размеры, параметры
+------------------+
| Display Mesh     |  ← Треугольники для 3D отображения
+------------------+
| Proxy Graphics   |  ← 2D графика для плана
+------------------+
| Текстовые данные |  ← UTF-16 LE строки
+------------------+
```

### 4.3 Типы геометрии в прокси-объектах

Прокси-объекты могут содержать:

1. **ACIS SAT данные** (3D тела)
   - Сигнатура: "ACIS" ($43495341)
   - B-rep геометрия (грани, рёбра, вершины)
   - Точное представление

2. **Display Mesh** (полигональная сетка)
   - Вершины (X, Y, Z - double)
   - Грани (индексы вершин)
   - Приближённое представление

3. **Proxy Graphics** (2D графика)
   - Линии, дуги, круги
   - Для отображения в плане

### 4.4 Пример извлечения данных

**Данные из строки 2807** (hex-строка):

```
B003000018000000880000001D000000...
```

**Расшифровка**:
- `B0030000` = 0x000003B0 = **944 байта** (размер данных)
- `18000000` = 0x00000018 = **24** (версия формата)
- `88000000` = 0x00000088 = **136** (смещение данных)
- `1D000000` = 0x0000001D = **29** (размер заголовка)

## 6. Чтение DXF в ZCAD

### 6.1 Модуль uzeentacdproxy.pas

**Класс GDBObjAcdProxy** загружает прокси-объекты:

```pascal
procedure GDBObjAcdProxy.LoadFromDXF(var rdr: TZMemReader; ...);
var
  hexData: string;
  parser: TProxyObjectParser;
  parseResult: TProxyParseResult;
begin
  // Чтение кода 310 (бинарные данные)
  hexData := rdr.ParseString;

  // Универсальный парсер
  parser := TProxyObjectParser.Create;
  try
    if parser.InitFromHex(hexData) then begin
      parseResult := parser.Parse;

      if parseResult.Valid then begin
        // Сохранение BBox
        FBBoxMinInOCS := parseResult.BBoxMin;
        FBBoxMaxInOCS := parseResult.BBoxMax;
        FBBoxLoaded := True;

        // Сохранение меша для отрисовки
        FMeshData := parser.GetMeshForDisplay;
      end;
    end;
  finally
    parser.Free;
  end;
end;
```

### 6.2 Модуль uzeentproxyparser.pas

**Универсальный парсер** извлекает геометрию:

```pascal
TProxyObjectParser = class
  function InitFromHex(hexData: string): Boolean;
  function Parse: TProxyParseResult;
  function GetMeshForDisplay: TProxyMeshData;
end;
```

**Типы геометрии**:

```pascal
TProxyGeometryType = (
  pgtUnknown,
  pgtACIS_SAT,      // ACIS SAT solid data
  pgtDisplayMesh,   // Polygonal mesh for display
  pgtProxyGraphics  // 2D proxy graphics
);
```

### 6.3 Отрисовка (FormatEntity)

**Приоритеты**:

1. **Меш из парсера** → отрисовка геометрии
2. **BBox** → отрисовка рамки (fallback)

```pascal
procedure GDBObjAcdProxy.FormatEntity(...);
begin
  if (FMeshData <> nil) and (FMeshData.FaceCount > 0) then
    DrawProxyMesh(DC)  // Приоритет 1
  else if FBBoxLoaded then
    DrawBBox(DC);      // Приоритет 2 (fallback)
end;
```

| Поток | Коды DXF | Что хранит | Пример |
