# Техническое задание: модуль uzcui_dimstyleedit

## 1. Общее описание

Модуль `uzcui_dimstyleedit` реализует диалоговое окно редактирования размерного стиля DXF,
аналог диалога «Изменение размерного стиля» в AutoCAD.

Форма строится **программно** (без использования визуального дизайнера форм, без `.lfm`-файла),
в том же стиле, что и модуль `uzcui_dimstylemanager`.

Диалог вызывается из менеджера размерных стилей (`TDimStyleManagerForm`) при нажатии кнопки
«Редактировать...» (метод `OnEditClick`). В диалог передаётся указатель на выбранный
размерный стиль (`PGDBDimStyle`).

## 2. Заголовок и общая структура окна

- **Заголовок окна:** `Изменение размерного стиля: <ИмяСтиля>`
- **Размер окна:** 566 x 523 пикселей (приблизительно, как на референсных изображениях)
- **Модальность:** модальный диалог (`ShowModal`)
- **Положение:** по центру родительского окна (`poMainFormCenter`)
- **Стиль границы:** `bsDialog`

### Основная компоновка

```
+---------------------------------------------------------------+
| Заголовок: Изменение размерного стиля: <ИмяСтиля>             |
+---------------------------------------------------------------+
| [Линии] [Символы и стрелки] [Текст] [Размещение]              |
| [Основные единицы] [Альт. единицы] [Допуски]                  |
+---------------------------------------------------------------+
|                                                                |
|                  Содержимое активной вкладки                   |
|                                                                |
+---------------------------------------------------------------+
|                          [OK] [Отмена] [Справка]              |
+---------------------------------------------------------------+
```

Верхняя часть — `TPageControl` с 7 вкладками (`TTabSheet`).
Нижняя часть — панель с кнопками «OK», «Отмена», «Справка».

## 3. Кнопки нижней панели

| Кнопка   | Действие                                                                                  |
|----------|-------------------------------------------------------------------------------------------|
| OK       | Применяет изменения к размерному стилю и закрывает диалог (`ModalResult := mrOk`)         |
| Отмена   | Закрывает диалог без сохранения изменений (`ModalResult := mrCancel`)                     |
| Справка  | Заблокирована (`Enabled := False`), с подсказкой «Справка не реализована на данном этапе»  |

При нажатии «OK» все значения из элементов управления записываются обратно в структуру `GDBDimStyle`.
Для отмены — при открытии окна сохраняется резервная копия значений стиля, которая
восстанавливается при нажатии «Отмена».

## 4. Предпросмотр (Preview)

На каждой вкладке в правой верхней части располагается область предпросмотра (`TPaintBox`
или `TImage`).

**На данном этапе предпросмотр НЕ разрабатывается** — вместо него размещается
картинка-заглушка: серый прямоугольник с текстом «Предпросмотр недоступен» по центру
(аналогично заглушке в `uzcui_dimstylemanager`).

Размер области предпросмотра: приблизительно 250 x 200 пикселей, размещена в правой
верхней части каждой вкладки.

## 5. Неразработанные параметры

Если структура размерного стиля (`GDBDimStyle`) **не содержит** поля для какого-либо
параметра, отображаемого на форме, то:

- Элемент управления **отображается**, но **заблокирован** (`Enabled := False`)
- При наведении мыши показывается подсказка: `Hint := 'Данный параметр не разработан'`
- Свойство `ShowHint := True`

Логика DIMZIN (группа DXF 78):
- Значение 0: отображать все нули
- Значение 1: подавить 0 футов
- Значение 2: подавить 0 дюймов
- Значение 3: подавить и 0 футов, и 0 дюймов

- Значение 8: подавить хвостовые нули

Чекбоксы «Ведущие» и «Хвостовые» работают с битами 2 и 3 (значения 4 и 8).
Чекбоксы «0 футов» и «0 дюймов» работают с битами 0 и 1 (значения 1 и 2).

## 8. Интеграция с менеджером стилей

В модуле `uzcui_dimstylemanager.pas` метод `OnEditClick` заменяется с заглушки на вызов:

```pascal
procedure TDimStyleManagerForm.OnEditClick(Sender: TObject);
var
  StylePtr: PGDBDimStyle;
  EditForm: TDimStyleEditForm;
begin
  StylePtr := GetSelectedStyle;
  if StylePtr = nil then
    Exit;

  EditForm := TDimStyleEditForm.Create(Self);
  try
    EditForm.SetDimStyle(StylePtr);
    SetHeightControl(EditForm, sysvar.INTF.INTF_DefaultControlHeight^);
    if EditForm.ShowModal = mrOk then
    begin
      { Обновляем предпросмотр в менеджере }
      RefreshStyleList;
    end;
  finally
    EditForm.Free;
  end;
end;
```

В секцию `uses` менеджера добавляется `uzcui_dimstyleedit`.

## 10. Принципы реализации

1. **Программное построение формы** — без `.lfm`-файла, аналогично `uzcui_dimstylemanager`.
2. **Константы для размеров** — все размеры элементов (ширина, высота, отступы) вынесены
   в именованные константы в секции `const`.
3. **Один элемент — одно поле** — каждый элемент управления привязан к одному полю стиля
   (или помечен как нереализованный).
4. **Компактные функции** — каждая функция не более 30 строк.
5. **Комментарии на русском языке** — описывают назначение и логику.
6. **Нет магических чисел** — все числовые значения через константы.
7. **Заглушка предпросмотра** — серый прямоугольник с текстом, без реальной отрисовки.
8. **Защита данных** — при отмене восстанавливается резервная копия стиля.
