# Анализатор стен ZCAD

1. Откройте чертёж и введите `WallAnalyze`. Можно заранее выделить исходные
   объекты. Если выделения нет, укажите две противоположные точки прямоугольника.
   Анализируются целиком попавшие в прямоугольник объекты модели. Введите минимум
   и максимум толщины в единицах чертежа, например 100 и 300.
2. Проверьте бирюзовые границы и жёлтые оси кандидатов. Консоль показывает число
   пар, число отклонённых пар и диапазон толщин. Команда `WallSend` разрешает
   внешнему клиенту получить эти участки границ и оси. Команда `WallCancel`
   закрывает предпросмотр.
3. Запустите `HTTPStart` и внешний клиент. Клиент передаёт подтверждённый JSON
   выбранному классификатору и возвращает ответ в ZCAD.

   ```sh
   python3 wall_client.py -- python3 /path/to/classifier.py
   ```

4. Проверьте пурпурные оси результата и статистику уверенности в консоли.
   Введите `WallCommit`, чтобы создать полилинии, или `WallCancel`.
   Одна команда `Undo` удаляет все полилинии, созданные этим подтверждением.

`LINE` и прямые сегменты `LWPOLYLINE` обрабатываются в WCS. Допуск на
угол составляет 1°, минимальное продольное перекрытие — 0,001 единицы чертежа.
Толщина проверяется на общем участке. Предпросмотр использует слой
`ZCAD_AI_WALL_PREVIEW` с отключённой печатью. Слой должен быть включён и
непечатным. Объекты пользователя на этом слое сохраняются. Изменение или удаление
исходного объекта после анализа аннулирует результат.

## HTTP IPC

Отправляйте POST на `/ipc` существующего HTTP-сервера. Поле `result` в
успешном ответе содержит JSON-строку. Для клиента можно задать другой адрес
через `--endpoint` и существующий токен IPC через `ZCAD_IPC_TOKEN`.

| Команда | `args` | Результат |
| --- | --- | --- |
| `WALL_ANALYZE` | `[{"window":[[0,0],[5000,5000]],"min_thickness":100,"max_thickness":300}]` | Создаёт сессию и показывает кандидатов. Вместо `window` принимается `handles`, массив HANDLE объектов. Если оба аргумента отсутствуют, используется выделение. |
| `WALL_PREVIEW` | `[]` или `[session_id]` | Возвращает этап и статистику предпросмотра. Пустой запрос позволяет узнать текущую сессию. |
| `WALL_SEND_AI` | `[session_id]` | После `WallSend` возвращает геометрию предпросмотра. |
| `WALL_AI_RESULT` | `[response]` | Проверяет ответ внешнего классификатора и показывает оси стен. |
| `WALL_COMMIT` | `[session_id]` | Запрашивает подтверждение в ZCAD или возвращает результат уже завершённой сессии. |
| `WALL_CANCEL` | `[session_id]` | Отменяет сессию и убирает предпросмотр. |

Классификатор читает из стандартного ввода один объект JSON с `session_id` и
массивом `candidates`. Для каждого кандидата передаются `candidate_id`,
`source_handles`, `thickness`, угол, длина перекрытия, смещение и геометрия
предпросмотра в полях `boundaries` и `centerline`. Координаты имеют вид
`[x,y,z]`. Если у объекта ещё нет DXF HANDLE, поле `temporary_handle` на
границе обозначает ссылку, действующую в пределах текущей сессии.

Ответ классификатора в стандартном выводе содержит один объект JSON. Идентификаторы
и ссылки на исходные объекты возвращаются из запроса. Для `is_wall: false`
достаточно вернуть `candidate_id`, `is_wall`, `confidence` и
`source_handles`.

```json
{
  "session_id": "{ECAFFC01-0FD2-44F9-A503-C1C8ED08E735}",
  "walls": [
    {
      "candidate_id": "C1",
      "is_wall": true,
      "confidence": 0.93,
      "thickness": 200,
      "source_handles": ["A1", "A2"],
      "centerline": {"vertices": [[150,100,0],[1000,100,0]]}
    }
  ]
}
```

По итогам создаются `LWPOLYLINE` с постоянной отметкой Z или пространственные
`POLYLINE`. Метаданные DXF записываются через существующий APPID `DSTP_XDATA`
с префиксом `ZCAD_WALLS_` для полей `OBJECT_TYPE`, `WALL_ID`,
`REPRESENTATION`, `THICKNESS`, `CONFIDENCE`, `SOURCE`, `SESSION_ID`
и `SOURCE_HANDLES`. `INPUT_HANDLES` хранит ссылки из запроса, а
`SOURCE_HANDLES` использует HANDLE исходных сущностей в экспортируемом DXF.

## Проверка

- Логику геометрии и проверки JSON можно запустить через `fpc -Fu. test_walls.pas`
  и `./test_walls`.
- Автоматизированная проверка в Linux использует работающий ZCAD, запущенный
  `HTTPStart`, `xdotool` и идентификатор окна. Скрипт создаёт DXF и прогоняет
  внешний тестовый классификатор. Координаты поля командной строки указываются
  относительно окна. Для `--screenshots` нужен Pillow. Параметр `--history X Y`
  прокручивает историю команд перед снимком, если указать точку внутри неё.

  ```sh
  python3 test_wall_workflow.py --window WINDOW_ID --console X Y --output /tmp/zcad-walls
  ```
