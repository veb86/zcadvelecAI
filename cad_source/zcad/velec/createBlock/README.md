# createBlock

## Назначение

Модуль предоставляет команду `CreateBlockInsert` — создание нового блока (BlockDef)
из выделенных на чертеже примитивов с последующим предложением вставки этого блока.

## Что содержит

- `uzccommand_createblockinsert.pas` — реализация команды `CreateBlockInsert`.

## Команды CAD

- `CreateBlockInsert` — создаёт блок из выделенных примитивов.

  Алгоритм работы:
  1. Проверка наличия выделенных примитивов. Если выделения нет — выводится
     сообщение и команда завершается.
  2. Запрос базовой точки блока (точки, относительно которой будут пересчитаны
     координаты примитивов внутри блока).
  3. Запрос имени нового блока через командную строку ZCAD.
  4. В чертеже создаётся новый `BlockDef`, в который добавляются копии всех
     выделенных примитивов со смещением относительно базовой точки.
  5. После успешного создания блока сразу запускается команда `Insert` с
     подставленным именем нового блока — пользователю остаётся указать место
     вставки.

## Взаимодействие с другими модулями

**Использует:**
- `uzcdrawings` — менеджер чертежей и выделенных примитивов.
- `uzeblockdef` — описание объекта `GDBObjBlockdef`.
- `uzeentwithlocalcs` — пересчёт локальных систем координат при копировании.
- `uzccommandsmanager` — диалог через командную строку (Get3DPoint/GetInput).
- `uzclog` — логирование.

**Используется:**
- Внешними сценариями, запускающими команду `CreateBlockInsert` из меню или
  командной строки ZCAD.
