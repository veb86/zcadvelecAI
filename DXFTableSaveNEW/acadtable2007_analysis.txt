4.1. Тип объекта таблицы:
    - DXF использует ACAD_TABLE как тип сущности
    - Subclass marker: AcDbTable

4.2. Структура ACAD_TABLE:
    - Handle (group 5): уникальный идентификатор
    - Owner (group 330): ссылка на BLOCK_RECORD
    - Layer (group 8): слой
    - Binary data (group 310): содержит сериализованные данные ячеек
    - Insert point (groups 10,20,30): координаты вставки
    - Table style (group 342): ссылка на TABLESTYLE
    - Block record (group 343): ссылка на блок таблицы

4.3. Разделение таблицы (TABLE BREAK):
    - Обнаружено 3 связанных ACAD_TABLE фрагмента единой таблицы
    - Каждая таблица имеет свой insert point:
      * Table 1: (84.67, 20.50) - 10 строк x 5 колонок
      * Table 2: (94.69, 15.05) - 6 строк x 5 колонок
      * Table 3: (107.47, 11.11) - 5 строк x 5 колонок
    - Все фрагменты ссылаются на единый TABLESTYLE (handle 87)
    - ФЛАГИ РАЗБИЕНИЯ (Group 90 = 22, 0b10110, 0x16):
      * 0x02 (kTableBreakEnable): ВКЛЮЧЕНО (Table Break активен!)
      * 0x04 (kTableBreakAuto): ВКЛЮЧЕНО (Автоматическая высота / перенос)
      * 0x10 (kTableBreakRepeatHeader / CustomOffsets): ВКЛЮЧЕНО (Повтор заголовков)
    - ВЫВОД: AutoCAD использует нативный механизм Table Break. Во всех фрагментах
      разбиение включено (Group 90 = 22), где каждый фрагмент сохраняет
      свою позицию вставки, количество строк и ссылку на стиль.
